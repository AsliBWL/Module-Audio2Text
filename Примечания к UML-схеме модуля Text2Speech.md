### Класс Config

Класс `Config` отвечает за хранение конфигурации, т. е. значений параметров настройки модуля Text2Speech.

**Атрибуты:**
- `model_name` — имя выбранной модели Text2Speech;
- `qwen_model_name` — имя конкретной модели Qwen3-TTS;
- `qwen_language` — язык генерации речи для модели Qwen3-TTS;
- `qwen_speaker` — имя встроенного голоса для модели Qwen3-TTS;
- `path_to_audio_for_clone` — путь к аудиофайлу с голосом для клонирования для модели Qwen3-TTS;
- `text_for_clone` — текст, который произносится в аудиофайле `path_to_audio_for_clone`;
- `instruct` — инструкции для управления тоном и эмоциями или для создания голоса по описанию для модели Qwen3-TTS;
- `qwen_device` — устройство для вычислений модели Qwen3-TTS;
- `dtype` — тип данных для весов модели Qwen3-TTS; `torch.dtype` – класс из библиотеки PyTorch, который определяет тип данных, хранящихся внутри тензора PyTorch;
- `attn_implementation` — реализация механизма внимания для модели Qwen3-TTS;
- `silero_model_version` — версия модели Silero TTS;
- `silero_language` — язык генерации речи для модели Silero TTS;
- `silero_speaker` — имя встроенного голоса для модели Silero TTS;
- `sample_rate` — частота дискретизации синтезируемого аудио в Гц;
- `put_accent` — автоматическая расстановка ударений для модели Silero TTS;
- `put_yo` — автоматическая замена "е" на "ё" для модели Silero TTS;
- `silero_device` — устройство для вычислений модели Silero TTS.

### Класс AudioConverter

Утилитарный класс `AudioConverter` отвечает за конвертацию синтезированного аудио.

**Методы:**
- `int16_to_float32` — конвертация аудиоданные из формата int16 в float32 и нормализация их в диапазоне от -1 до 1.

---

### Класс AudioPlayer

Утилитарный класс `AudioPlayer` отвечает за воспроизведение синтезированного аудио.

**Методы:**
- `play_audio` — воспроизводство синтезированного аудио через динамик.

---

### Класс AudioBuilder

Класс `AudioBuilder` отвечает за хранение всех синтезированных аудио.

**Атрибуты:**
- `audio_list` — список для хранения синтезированных аудио в формате float32;
- `sample_rate_list` — список для хранения частот дискретизации соответствующих аудио.

**Методы:**
- `add_audio` — добавление синтезированного аудио и его частоты дискретизации в соответствующие списки.

---

### Класс Text2SpeechInterface

Абстрактный класс `Text2SpeechInterface` служит базовым интерфейсом для всех синтезаторов речи.

**Методы:**
- `synthesis` — преобразование текста в аудиоданные.

---

### Класс Qwen3Synthesizer

Класс `Qwen3Synthesizer` — это реализация синтеза речи с использованием модели Qwen3-TTS.

**Атрибуты:**
- `config` — конфигурация, содержащая параметры модуля Text2Speech;
- `model` — модель синтеза речи Qwen3-TTS; `Qwen3TTSModel` – класс из библиотеки `qwen_tts`.

---

### Класс SileroSynthesizer

Класс `SileroSynthesizer` — это реализация синтеза речи с использованием модели Silero TTS.

**Атрибуты:**
- `config` — конфигурация, содержащая параметры модуля Text2Speech;
- `model` — модель синтеза речи Silero TTS; `torch.hub.load` – класс из библиотеки PyTorch.

---

### Класс Context

Класс `Context` объединяет в себе все объекты, необходимые для синтеза аудио: конфигурацию, модель синтеза, плеер и сборщик аудио.

**Атрибуты:**
- `config` — конфигурация, содержащая параметры модуля Text2Speech;
- `t2s_model` — объект синтезатора речи, реализующий интерфейс `Text2SpeechInterface`;
- `builder` — объект класса `AudioBuilder` для хранения синтезированных аудио.

**Методы:**
- `start` — основной метод синтеза. Принимает текст, синтезирует аудио через `t2s_model.synthesis()`, воспроизводит его через `AudioPlayer.play_audio()` и добавляет в `builder` через `builder.add_audio()`.
