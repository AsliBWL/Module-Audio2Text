# Введение

**VAD** — детектор голосовой активности; нужен для проверки аудиоданных на наличие в них речи, чтобы не отправлять на модель распознавания аудиоданные без речи.

**Фрейм** — отрезок аудиоданных, который VAD проверяет на наличие речи; состоит из семплов (образцов звука).

**Фраза** — отрезок аудиоданных между паузами, т. е. фреймами, в которых нет речи.

> **Примечание:** Программа может работать только с моноаудио (1 канал звука), но возможна ее доработка для стереоаудио. Однако в этом нет смысла, потому что модель Whisper перед распознаванием приводит стереоаудио к моноаудио.


# Класс `Config`

Класс `Config` отвечает за хранение конфигурации (т. е. значений параметров настройки) модуля Speech2Text.

### Атрибуты:

- `sample_rate` — частота дискретизации аудио в Гц;
- `vad_frame_samples` — размер фрейма в семплах;
- `bytes_per_sample` — количество байт на 1 семпл;
- `whisper_model_version` — версия модели Whisper;
- `device` — устройство, на котором модель распознавания будет производить вычисления;
- `compute_type` — тип вычислений модели распознавания;
- `vad_threshold` — порог срабатывания VAD;
- `min_silence_duration_ms` — минимальная длительность тишины, для того чтобы считать фразу завершенной, в мс;
- `speech_pad_ms` — длительность добавочной тишины, которая добавляется в начало и конец фрейма перед отправкой фрейма на VAD;
- `beam_size` — количество наиболее вероятных вариантов расшифровки аудио;
- `auto_language` — автоопределение языка речи;
- `language` — язык, на котором будет распознаваться речь.


# Класс `AudioSource`

Абстрактный класс `AudioSource` служит базовым интерфейсом для всех источников аудио (микрофон, файл, сетевой поток).


# Класс `MicrophoneSource`

Класс `MicrophoneSource` отвечает за захват аудио с микрофона.

### Атрибуты:

- `config` — конфигурация, содержащая параметры модуля Speech2Text;
- `audio_queue` — очередь для хранения аудиоданных, полученных с микрофона; `Queue` — класс из библиотеки `queue`;
- `callback` — пользовательская callback-функция, которая вызывается каждый раз, когда в `audio_queue` добавляются новые аудиоданные;
- `stream` — аудиопоток; `RawInputStream` — класс из библиотеки `sounddevice`;
- `_is_running` — флаг "Запущен ли захват аудио с микрофона".

### Методы:

- `_audio_callback` — callback-функция, которую вызывает `_stream` каждый раз, когда на микрофон приходят новые аудиоданные; она забирает аудиоданные с микрофона и кладет их в `audio_queue`; `channels` — количество каналов звука;
- `start()` — запуск захвата аудио с микрофона;
- `stop()` — остановка захвата аудио с микрофона;
- `get_audio_chunk()` — получение следующего фрейма из `audio_queue`;
- `is_running()` — проверка, запущен ли захват аудио.


# Класс `SessionContext`

Класс `SessionContext` отвечает за поддержку состояния сессии распознавания ("сейчас говорим/не говорим") и буферизацию аудиоданных. Аудиоданные приходят от микрофона фреймами на VAD. VAD анализирует их, но не может накапливать речь между фреймами.

Класс `SessionContext` служит "буфером" и "памятью":

- накапливает семплы, пока не наберётся полный фрейм для VAD;
- хранит состояние сессии распознавания (говорит ли пользователь прямо сейчас);
- собирает фреймы, пока не закончится фраза (пока пользователь говорит);
- когда речь закончилась, отдаёт всю накопленную фразу распознавателю.

### Атрибуты:

- `config` — конфигурация, содержащая параметры модуля Speech2Text;
- `frame_bytes_len` — размер фрейма в байтах;
- `pending_bytes` — буфер для хранения всех фреймов, приходящих с микрофона, в байтах;
- `pending_float` — буфер для хранения всех фреймов, приходящих с микрофона, в вещественном нормализованном формате (только в таком формате их можно подать на VAD);
- `in_speech` — флаг "Говорит ли пользователь сейчас";
- `speech_segment` — буфер для хранения фразы в байтах.

### Методы:

- `add_audio_chunk(audio_bytes)` — добавление в `pending_bytes` фрейма, полученного от микрофона;
- `has_complete_frame()` — проверка, есть ли в `pending_float` и `pending_bytes` хотя бы 1 фрейм;
- `pop_frame()` — извлечение следующего фрейма из `pending_float` и `pending_bytes` для отправки на VAD;
- `start_speech()` — начало записи речи; вызывается, когда VAD обнаруживает речь во фрейме;
- `accumulate_speech(frame_bytes)` — добавление в `speech_segment` фрейма с речью;
- `end_speech()` — завершение записи речи; вызывается, когда VAD обнаруживает тишину во фрейме;
- `reset()` — сброс состояния сессии распознавания.


# Класс `VADInterface`

Абстрактный класс `VADInterface` отвечает за детекцию голосовой активности.

### Методы:

- `process_frame(frame_float)` — проверка фрейма на наличие в нем речи;
- `reset()` — сброс внутреннего состояния VAD.


# Класс `SileroVADDetector`

Класс `SileroVADDetector` — это реализация VAD с использованием модели Silero.

### Атрибуты:

- `config` — конфигурация, содержащая параметры модуля Speech2Text;
- `_vad_model` — модель Silero VAD; `SileroVADONNX` — класс из библиотеки `silero_vad`;
- `_vad_iterator` — итератор Silero VAD для поддержания состояния между вызовами VAD; `VADIterator` — класс из библиотеки `silero_vad`.

### Методы:

- `process_frame(frame_float)` — проверка фрейма на наличие в нем речи;
- `reset()` — сброс внутреннего состояния VAD.


# Класс `SpeechRecognizerInterface`

Абстрактный класс `SpeechRecognizerInterface` отвечает за распознавание речи, т. е. за преобразование аудио в текст.

### Методы:

- `recognize(audio)` — преобразование аудиоданных в текст.


# Класс `FasterWhisperRecognizer`

Класс `FasterWhisperRecognizer` — это реализация распознавания речи через библиотеку `faster-whisper`.

### Атрибуты:

- `config` — конфигурация, содержащая параметры модуля Speech2Text;
- `model` — модель распознавания речи Whisper; `WhisperModel` — класс из библиотеки `faster_whisper`.

### Методы:

- `recognize(audio)` — преобразование аудиоданных в текст.


# Класс `RemoteWhisperRecognizer`

Класс `RemoteWhisperRecognizer` — это реализация распознавания речи через удалённый сервер whisper-live. Класс отправляет аудиоданные по протоколу WebSocket на удалённый сервер whisper-live и получает от него распознанный текст.

### Атрибуты:

- `config` — конфигурация, содержащая параметры модуля Speech2Text;
- `websocket_url` — WebSocket-адрес удалённого сервера whisper-live.

### Методы:

- `_send_audio_and_receive(audio)` — отправка аудиоданных на удалённый сервер whisper-live и получение от него результатов.


# Класс `SpeechBuilder`

Класс `SpeechBuilder` отвечает за сборку итогового текста из распознанных фраз.

### Атрибуты:

- `fragments` — массив для хранения распознанных фраз.

### Методы:

- `add_fragment(text)` — добавление очередной распознанной фразы в `fragments`;
- `build()` — склеивание всех распознанных фраз в итоговый текст;
- `clear()` — очищение `fragments` от накопленных фраз.


# Класс `AudioConverter` (утилитарный)

Утилитарный класс `AudioConverter` отвечает за конвертацию аудиоданных.

### Методы:

- `pcm16_to_float32(audio_bytes)` — конвертация фрейма из PCM int16 в float32 и его нормализация в диапазоне [-1; 1];
- `bytes_to_float32_samples(audio_bytes_list)` — объединение всех фреймов, входящих во фразу, в один массив и их конвертация из PCM int16 в float32 и нормализация в диапазоне [-1; 1].


# Класс `Context`

### Атрибуты:

- `config` — конфигурация, содержащая параметры модуля Speech2Text;
- `session` — буфер аудиоданных сессии распознавания;
- `vad` — детектор голосовой активности на основе модели Silero VAD;
- `recognizer` — распознаватель речи на основе модели Whisper, развернутой на удаленном сервере;
- `builder` — построитель итогового текста из распознанных фраз;
- `mic` — источник аудиоданных с микрофона.

### Методы:

- `start()` — запуск работы модуля Speech2Text.
