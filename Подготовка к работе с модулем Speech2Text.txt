1. Если пользователь планирует использовать GPU NVIDIA, необходимо отдельно установить PyTorch с
   поддержкой CUDA:
   -------------------------------------------------------------------------------------------------
   pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu118
   -------------------------------------------------------------------------------------------------
2. Выбрать нужное аудиоустройство согласно указаниям, изложенным в файле audio_device_selection.txt:
   файл audio_capture.py → класс MicrophoneSource → метод start() → инициализация атрибута _stream →
   параметр device.
3. Если пользователь хочет развернуть модель Whisper на локальном сервере, необходимо установить
   зависимости с помощью файла requirements_s2t.txt:
   -------------------------------------------------------------------------------------------------
   pip install -r requirements_s2t.txt
   -------------------------------------------------------------------------------------------------
4. Если пользователь хочет развернуть Whisper на удаленном сервере, необходимо на удаленном сервере
   (сервер с GPU, где будет развернута модель Whisper) установить зависимости с помощью файла
   requirements_server_gpu.txt:
   -------------------------------------------------------------------------------------------------
   pip install -r requirements_server_gpu.txt
   -------------------------------------------------------------------------------------------------
   а на локальном сервере (сервер с CPU, где будет запущен пользовательский код) установить
   зависимости с помощью файла requirements_client_cpu.txt:
   -------------------------------------------------------------------------------------------------
   pip install -r requirements_client_cpu.txt
   -------------------------------------------------------------------------------------------------
4. Если пользователь хочет развернуть модель Whisper на удаленном сервере, необходимо также выполнить
   указания, изложенные в файле Подключение к модели Whisper на другом ПК (с GPU).docx.
