1. Если пользователь планирует использовать модель Silero TTS, необходимо клонировать
   репозиторий с моделью Silero TTS:
   ------------------------------------------------------------------------------------
   git clone https://github.com/snakers4/silero-models.git silero_repo
   ------------------------------------------------------------------------------------
   (НО это не обязательно: репозиторий автоматичеки будет клонирован при первом запуске
   модели Silero TTS, но если пользователь не хочет, чтобы на клонирование тратилось
   время при первом запуске модели, репозиторий нужно клонировать вручную).
2. Если пользователь планирует использовать GPU NVIDIA, необходимо отдельно установить
   PyTorch с поддержкой CUDA:
   ------------------------------------------------------------------------------------
   pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu118
   ------------------------------------------------------------------------------------
3. Если пользователь планирует использовать алгоритм Flash Attention 2 для ускорения
   работы модели Qwen3-TTS, необходимо установить пакет flash-attn:
   ------------------------------------------------------------------------------------
   pip install flash-attn
   ------------------------------------------------------------------------------------
   ВАЖНО: Алгоритм Flash Attention работает только на GPU от NVIDIA с архитектурой
   Ampere, Ada Lovelace или Hopper (например, A100, RTX 3090, RTX 4090, H100).
4. Если пользователь планирует использовать алгоритм Flash Attention 3 для ускорения
   работы модели Qwen3-TTS, необходимо установить пакет kernels:
   ------------------------------------------------------------------------------------
   pip install -U kernels
   ------------------------------------------------------------------------------------
   ВАЖНО: Алгоритм Flash Attention работает только на GPU от NVIDIA с архитектурой
   Ampere, Ada Lovelace или Hopper (например, A100, RTX 3090, RTX 4090, H100).
5. Установить зависимости с помощью файла requirements_t2s.txt:
   ------------------------------------------------------------------------------------
   pip install -r requirements_t2s.txt
   ------------------------------------------------------------------------------------
6. Установить SoX (используется librosa при обработке аудио).
   SoX — это системная программа, она НЕ устанавливается через pip.
   Инструкция по установке для разных ОС:
    - Windows: 
        1. Скачайте установщик с http://sox.sourceforge.net/
        2. Запустите установку и запомните папку, куда установили SoX 
           (например, C:\Program Files (x86)\sox-14.4.2)
        3. ДОБАВЬТЕ ПУТЬ К ПАПКЕ С sox.exe В ПЕРЕМЕННУЮ PATH:
           - Нажмите Win+R, введите sysdm.cpl → Enter
           - Перейдите на вкладку "Дополнительно" → "Переменные среды..."
           - Найдите переменную Path, выберите "Изменить"
           - Добавьте новую строку с путём к папке SoX (например, C:\Program Files (x86)\sox-14.4.2)
           - Нажмите ОК во всех окнах и перезапустите терминал/среду разработки
    - Linux: sudo apt-get install sox (путь добавится автоматически)
    - macOS: brew install sox (путь добавится автоматически)
