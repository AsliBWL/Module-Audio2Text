# Модуль преобразования аудио в текст

## Описание модуля

На рисунке 1 представлена структурная схема модуля преобразования аудио в текст (далее модуль). Модуль с помощью микрофона постоянно получает звуки из окружающей среды и постоянно передает их модели **VAD**. Если модель VAD распознает в полученных звуках человеческую речь, модель VAD передает эти звуки модели **Speech2Text**. Модель Speech2Text распознает полученные звуки и преобразует их в текст. Полученный текст передается в **блок принятия решения**, который решает, передавать текст модели RAG или нет. Если полученный от модели Speech2Text текст является **активационным словом** (как слово «Алиса» для голосового помощника «Алиса»), то блок принятия решения подает сигнал на динамик, и динамик издает определенный звук, чтобы таким образом сообщить оператору, что модуль готов слушать запрос оператора. В этом случае весь следующий текст, полученный от модели Speech2Text, передается блоком принятия решения модели **RAG**.

**Сокращения:**

- **VAD** — Voice Activity Detection;
- **RAG** — Retrieval Augmented Generation.

## Функциональные требования к модулю:

1. Модуль должен обеспечивать непрерывный захват (захват в реальном времени) звуковой информации с микрофона и её потоковую передачу (стриминг) модели VAD.
2. Модуль должен издать определенный звук с помощью динамика (оповестить оператора), если оператор скажет активационное слово.
3. Модуль должен передать модели RAG весь текст, полученный от модели Speech2Text после произнесения оператором активационного слова и издания динамиком определенного звука.

## Нефункциональные требования к модулю:

1. Объем требуемой памяти — **2 Гб** (2 Гб — объем требуемой памяти для модели Whisper (small), 2 Мб — объем требуемой памяти для модели Silero VAD).
2. Требуется **микрофон**.
3. Требуется **динамик**.
4. Требуется **GPU**.

## Варианты использования (ВИ) модуля:

1. Пользователь (оператор) произносит в микрофон модуля активационное слово.
2. После ВИ 1. Пользователь (оператор) дожидается, когда динамик модуля издаст определенный звук.
3. После ВИ 2. Пользователь (оператор) произносит в микрофон свой запрос.
