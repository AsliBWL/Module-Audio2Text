# Модуль преобразования аудио в текст

## Описание модуля

На рисунке 1 представлена структурная схема модуля преобразования аудио в текст (далее модуль). Модуль с помощью микрофона постоянно получает звуки из окружающей среды и постоянно передает их модели VAD. Если модель VAD распознает в полученных звуках человеческую речь, модель VAD передает эти звуки модели Speech2Text. Модель Speech2Text распознает полученные звуки и преобразует их в текст. Полученный текст передается в модель RAG.

**Сокращения:**

- VAD — Voice Activity Detection;
- RAG — Retrieval Augmented Generation.

## Функциональные требования к модулю:

1. Модуль должен обеспечивать непрерывный захват (захват в реальном времени) звуковой информации с микрофона и её потоковую передачу (стриминг) модели VAD.

2. Модуль должен обеспечивать детекцию голосовой активности.

3. Модуль должен обеспечивать преобразование полученного от VAD аудио в текст.

4. Модуль должен передать модели RAG весь текст, полученный от модели Speech2Text после произнесения оператором активационного слова и издания динамиком определенного звука.

## Нефункциональные требования к модулю:

1. Объем требуемой памяти — 2 Гб (2 Гб — объем требуемой памяти для модели Whisper (small), 2 Мб — объем требуемой памяти для модели Silero VAD).

2. Требуется микрофон.

3. Требуется GPU.

## Варианты использования (ВИ) модуля:

1. Пользователь (оператор) произносит в микрофон модуля свой запрос.

# Модуль преобразования текста в аудио

## Описание модуля

На рисунке 2 представлена структурная схема модуля преобразования текста в аудио (далее модуль). Модель RAG генерирует текст и передает его модели LM. Модель LM преобразует сгенерированный текст так, чтобы числа и специальные символы были записаны словами. Это связано с тем, что модели Text2Speech не могут читать числа и специальные символы. Модель LM передает преобразованный текст модели Text2Speech. Модель Text2Speech по полученному тексту синтезирует аудио и передает его на динамик, который озвучивает синтезированное аудио.

**Сокращения:**

- RAG — Retrieval Augmented Generation;
- LM — Language Model.

**Обозначения:**

- текст 1 — текст, полученный от модели RAG (с числами и специальными символами);
- текст 2 — текст 1, преобразованный моделью LM таким образом, чтобы числа и специальные символы в нем были написаны словами (например, °C — градусов по Цельсию).

## Функциональные требования к модулю:

1. Модуль должен синтезировать аудио на основе полученного текста.

2. Модуль должен озвучивать синтезированное аудио.

## Нефункциональные требования к модулю:

1. Объем требуемой памяти — 3,8 Гб (3,8 Гб — объем требуемой памяти для модели Qwen3-TTS (рассматривается версия модели Qwen3-TTS с наибольшим размером) при условии, что dtype=torch.bfloat16; 138 Мб — объем требуемой памяти для модели Silero TTS (для всех версий модели Silero TTS)).

2. Требуется динамик.

3. Требуется GPU.

## Варианты использования (ВИ) модуля:

1. Пользователь (оператор) отправляет на модуль текст, по которому нужно синтезировать аудио.
