# Модуль преобразования аудио в текст

## Описание модуля

На рисунке 1 представлена структурная схема модуля преобразования аудио в текст (далее модуль). Модуль с помощью микрофона постоянно получает звуки из окружающей среды и постоянно передает их модели VAD. Если модель VAD распознает в полученных звуках человеческую речь, модель VAD передает эти звуки модели Speech2Text. Модель Speech2Text распознает полученные звуки и преобразует их в текст. Полученный текст передается в модель RAG.

**Сокращения:**

- VAD — Voice Activity Detection;
- RAG — Retrieval Augmented Generation.

## Функциональные требования к модулю:

1. Модуль должен обеспечивать непрерывный захват (захват в реальном времени) звуковой информации с микрофона и её потоковую передачу (стриминг) модели VAD.

2. Модуль должен обеспечивать детекцию голосовой активности.

3. Модуль должен обеспечивать преобразование полученного от VAD аудио в текст.

4. Модуль должен передать модели RAG весь текст, полученный от модели Speech2Text после произнесения оператором активационного слова и издания динамиком определенного звука.

## Нефункциональные требования к модулю:

1. Объем требуемой памяти — 2 Гб (2 Гб — объем требуемой памяти для модели Whisper (small), 2 Мб — объем требуемой памяти для модели Silero VAD).

2. Требуется микрофон.

3. Требуется GPU.

## Варианты использования (ВИ) модуля:

1. Пользователь (оператор) произносит в микрофон модуля свой запрос.

## Модели VAD и Speech2Text

Выбранные модели VAD и Speech2Text представлены в таблице 1.

Таблица 1 – Выбранные модели VAD и Speech2Text

| **Тип модели** | **Наименование модели** |
|:---:|:---|
| VAD | Silero VAD (интегрирован в пакет faster-whisper) |
| VAD | Псевдо-VAD (встроен в модель Vosk, реализован через метод AcceptWaveform класса KaldiRecognizer, определяет границы фраз простыми алгоритмами, например, на основе глобального порога тишины, в отличие от VAD, которая обучена обнаруживать человеческую речь) |
| VAD | Silero VAD (если нужна совместная работа модели Vosk с моделью VAD, то на практике в качестве модели VAD выбирают Silero VAD) |
| Speech2Text | Whisper (small) — для реального пользования (тяжелая, работает на GPU) |
| Speech2Text | Vosk (small) — для демонстрации (оптимизирована для работы на CPU) |
